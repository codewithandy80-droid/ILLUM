# ILLYUM — Acceptance Tests & Definition of Done

Use these tests during implementation. Add implementation-specific tests only when they do not weaken or replace these requirements.

## A. Project and source
- A1: User can create, open, rename, and revisit a project.
- A2: Projects do not show each other's source or generated content.
- A3: Pasted story source is saved and visible after refresh/reopen.
- A4: Unsupported or inaccessible URL/file source is clearly reported; app does not claim extraction succeeded.

## B. Skill 1
- B1: User can select Hindi or English.
- B2: User can select total duration.
- B3: Generated parts are duration-dependent, not fixed to four.
- B4: No part exceeds 8 seconds.
- B5: First part is Hook; middle parts are Story; final part is Ending.
- B6: Output includes part number, part type, voiceover, estimated duration.
- B7: Output preserves source facts and flags gaps; no invented facts.
- B8: User can edit, save, and approve a script.
- B9: A new generation preserves prior approved versions.

## C. Skill 2
- C1: Skill 2 is blocked unless an approved Skill 1 script exists.
- C2: Each script part has one video prompt.
- C3: Each prompt states duration, ratio, and resolution explicitly.
- C4: Prompts include all required visual, camera, lighting, action, character, environment, and continuity fields.
- C5: Exact approved voiceover is included and not rewritten.
- C6: Voice and music identity remain consistent across parts.
- C7: Text prompts only; no storyboard images are generated by this skill.
- C8: Skill 2 does not directly use the original story source.

## D. Skill 3
- D1: Skill 3 is blocked unless an approved Skill 1 script exists.
- D2: Exactly two options are produced.
- D3: A and B are genuinely different concepts, not simple color variations.
- D4: Strongest visual moment is selected from the whole script.
- D5: Ratio is explicit and matches selected output.
- D6: Prompts include mobile readability, hierarchy, text recommendation, quality constraints.
- D7: Text prompts only; no image is generated by this skill.
- D8: Skill 3 does not directly use original source story.

## E. Skill 4
- E1: Skill 4 requires both original source story and approved script.
- E2: Source and script are analyzed separately and together.
- E3: YouTube SEO and Instagram SEO are separate tabs/records.
- E4: YouTube title exactly matches first hook text.
- E5: YouTube description omits original article title, author, website, and link.
- E6: YouTube tags include all required groups and are comma-separated.
- E7: Instagram caption, keywords, hashtags, disclosure are present.
- E8: Live keyword claims are evidence-based; no fabricated metrics/trends.
- E9: No ranking/virality guarantee.

## F. Dependency, data and operations
- F1: Downstream skills are blocked when required script is unapproved.
- F2: Changing the approved script marks older dependent results Stale.
- F3: Output records identify source/script versions used.
- F4: Generation failures preserve user input and show retry guidance.
- F5: Progress/status matches actual execution and saved records.
- F6: User can copy outputs and export where supported.
- F7: App remains usable after refresh/reopen with selected persistence approach.
- F8: Secrets are not exposed in client code or UI.
- F9: Tracker and phase audit are updated at every phase boundary.

## Final completion gate
All applicable tests pass, no critical requirement is missing, known limitations are documented, the user has reviewed the app, and the final phase is explicitly accepted.
